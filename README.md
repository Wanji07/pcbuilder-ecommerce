# PCBuilder

> **BUILD. UPGRADE. PERFORM.**

PCBuilder is a proposed e-commerce website for computer parts and accessories, developed as the Final Project for **ITE 011 – Introduction to Computing**.

The project focuses on creating a clean, organized, and user-friendly shopping experience for students, PC builders, gamers, and computer enthusiasts.

## 🎯 Project Objectives

- Develop a functional e-commerce website using HTML5 and CSS
- Create a clear and user-friendly navigation system
- Present computer components and accessories through organized product pages
- Implement responsive and visually consistent web layouts
- Apply concepts learned throughout the course

## 🛠️ Technologies

- CSS3
- Javascript

## 🛍️ Shop Catalog

The shop page includes 10 sample products in each of its six categories: CPU, GPU, RAM, Storage, Case, and Mouse. Prices are estimates for demonstration only and should be checked against current Philippine retailer listings before publication. New catalog items use clearly labeled, original category illustrations until product photos are added. The shop's separate `src/js/shop.js` script filters products by category, brand, availability, and search text.

To preview the shop in VS Code, open `src/pages/shop.html`, right-click it, and select **Open with Live Server**.
