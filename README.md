# PCBuilder

> **BUILD. UPGRADE. PERFORM.**

PCBuilder is a proposed e-commerce website for computer parts and accessories, developed as the Final Project for **ITE 011 – Introduction to Computing**.

The project focuses on creating a clean, organized, and user-friendly shopping experience for students, PC builders, gamers, and computer enthusiasts.

## 🎯 Project Objectives

- Develop a functional e-commerce website using HTML5 and CSS
- Create a clear and user-friendly navigation system
- Present computer components and accessories through organized product pages
- Implement responsive and visually consistent web layouts
- Apply concepts learned throughout the course

## 🛠️ Technologies

- HTML5
- CSS3
- Javascript
- Git / Github
